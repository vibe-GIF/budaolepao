# 本地可视化控制台

## 启动

在完整源码目录完成 editable 安装后执行 `lepao web`，浏览器打开
`http://127.0.0.1:8765`。不需要 Node.js、前端构建或在线地图密钥。
控制台不加载外部字体、地图瓦片或 CDN，也不会向地图服务发送路线。

使用 `lepao web --port 8766` 可更换端口。保留终端窗口，按 Ctrl+C 关闭服务。
网页关闭不会停止已经开始的任务；离开前可先点击停止。

## 第一次使用

1. 打开控制台，检查配置来源。没有 `config.json` 时会展示示例配置；保存后才生成个人配置。
2. 修改目标里程、速度上下限和路线。路线每行一个 `经度,纬度`，至少三个不同点，末尾不要重复首点。
3. 先运行一次**本地预演**，检查路线、状态、日志及停止按钮。预演在约 8 秒内加速展示整个目标里程，显示的时长为按配置速度推算的时长。路线示意图不是实际地图，也不表示学校的有效路线。
4. 要使用模拟器，填写包含 `MuMuManager.exe`、`adb.exe` 的目录及 MuMu 启动程序路径。
5. 在对应 App 版本中获取并裁剪按钮截图，上传 PNG 模板。每个文件不超过 2 MiB；文件名由按钮类型决定。
6. 阅读准备检查结果，修复缺项后启动模拟器任务。App 的安装、登录和需要人工完成的步骤由使用者处理。

目前默认按钮流程仍为“开始乐跑 → 自由跑确认 → 暂停 → 结束 → 确认结束”。
没有实现通用校园跑流程、随机打卡点、人脸核验或官方成绩核验。
仓库缺少 `free_run.png`，其余模板也需要按当前 App 核对。

## 状态与结果

| 状态 | 含义 |
| --- | --- |
| idle | 当前没有任务 |
| running | 任务正在运行 |
| stopping | 已请求停止，正在结束本工具的任务 |
| stopped | 本工具的任务已停止，需要检查 App 是否仍在运行 |
| completed | 本地循环完成，平台结果未验证 |
| failed | 配置、设备操作或子进程出错，查看日志定位原因 |

进度中的距离、速度和步数都是本地计算值。`platform_accepted` 始终为 `null`，
不能用 `completed` 推断平台成绩有效。本地预演不会发送任何模拟器位置或 App 操作。
服务重启不会恢复之前的任务或内存日志。

## 网页与 MCP

两种入口共用同一个控制服务。网页上启动的任务可通过 MCP 查看或停止，反之亦然。
运行期间不能修改本次任务的配置、路径或模板，避免使用到混合版本的参数。
配置保存支持版本检查；如果网页和 MCP 同时编辑，过期草稿会被拒绝保存并保留在表单中。
已有配置损坏时，可显式“载入示例草稿”，检查后再保存；载入草稿本身不会覆盖文件。
日志使用递增游标，服务器只保留有限条目，长时间运行时较早日志会被淘汰。

服务仅绑定 `127.0.0.1`，校验请求 Host、Origin 和本地会话令牌。MCP 通过
`.lepao/controller.json` 发现服务；不要把该目录提交到仓库或发送给其他人。
这套接口用于本机控制，不提供远程部署或任意 shell 命令执行功能。

如果进程异常退出而留下发现文件，下次启动会提示文件已存在。先确认旧控制台进程已经退出，
再删除 `.lepao/controller.json` 后重启；不要删除仍在使用中的服务文件。
